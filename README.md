# Data from the Study of Frequency Asymmetry and Lexical Interference in Slovak–Russian Interlingual Homonymy

This repository contains the data, experimental materials, and analysis script used in the study *Frequency Asymmetry and Lexical Interference in Slovak–Russian Interlingual Homonymy: A Corpus-Based and Behavioral Study*.

The dataset includes corpus-based frequency data for 579 Slovak–Russian interlingual homonym pairs and behavioral data from 45 participants. The corpus data include IPM frequencies, frequency log-ratios, and frequency-dominance classifications.

The behavioral dataset contains 1,710 anonymized responses from 38 valid experimental items based on 20 lexical pairs, tested in Slovak→Russian production and Russian→Slovak receptive tasks.

A Python script for reproducible statistical analysis is also provided.
